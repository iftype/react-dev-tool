# React DevTools 사용법 소개

React Developer Tools는 React 애플리케이션의 컴포넌트 트리를 검사하고 렌더링 성능을 프로파일링할 수 있는 공식 브라우저 확장 프로그램입니다.

## 1. 설치 방법

- **Chrome / Edge / Brave**: Chrome 웹 스토어에서 "React Developer Tools"를 검색하여 설치합니다.
- **Firefox**: Firefox Add-ons에서 "React Developer Tools"를 검색하여 설치합니다.

설치가 완료되면 브라우저 개발자 도구(F12 또는 Cmd+Option+I)에 **⚛️ Components**와 **⚛️ Profiler** 탭이 추가됩니다.

## 2. Components 탭

**Components** 탭에서는 현재 화면에 렌더링된 React 컴포넌트 트리를 확인할 수 있습니다.

- **상태 및 Props 확인**: 선택한 컴포넌트가 현재 어떤 `props`를 받고 있으며, 어떤 `state`와 `hooks`를 가지고 있는지 실시간으로 확인하고 수정할 수 있습니다.
- **DOM 엘리먼트 추적**: 눈 모양 아이콘을 클릭하면 해당 React 컴포넌트가 실제 DOM에서 어디에 위치하는지 하이라이트됩니다.
- **디버깅**: 벌레 모양 아이콘을 클릭하면 컴포넌트의 데이터를 콘솔에 출력할 수 있습니다.

## 3. Profiler 탭

**Profiler** 탭은 애플리케이션의 렌더링 성능을 측정하고 병목(Bottleneck) 현상을 찾는 데 사용됩니다.

- **기록 시작**: 파란색 원(Record) 버튼을 눌러 프로파일링을 시작합니다.
- **상호작용**: 성능을 측정하고 싶은 동작(예: 버튼 클릭, 타이핑 등)을 앱에서 수행합니다.
- **기록 중지**: 빨간색 원(Stop) 버튼을 눌러 프로파일링을 종료합니다.

### Flamegraph 차트와 Ranked 차트
- **Flamegraph 차트**: 컴포넌트 트리의 렌더링 시간을 계층 구조로 보여줍니다. 너비가 넓을수록, 색상이 노란색에 가까울수록 렌더링에 오랜 시간이 걸렸다는 뜻입니다.
- **Ranked 차트**: 렌더링 시간이 가장 오래 걸린 컴포넌트부터 순서대로 나열하여 보여줍니다. 최적화 대상을 찾을 때 매우 유용합니다.
